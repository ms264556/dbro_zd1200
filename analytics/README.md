# Network Monitor (analytics) payload

This directory holds the browser-facing **Network Monitor** page and the
guest-side collectors it needs. The code is ported from the community
[`dbro/zd1200`](https://github.com/dbro/zd1200) project (upstream revision
`10aeb90`, the `public-release-candidate` merge), which runs a fully custom
ZD1200 userspace. This fork keeps the stock vendor rootfs and patches it after
each boot / upgrade, so only the payload is reused; the installation is
reworked in `scripts/container/patches/50-network-monitor.sh`.

## What it does

The page appears as the last item under **Troubleshooting** in the regular
admin console ("Network Monitor"). It records one ICMP observation per
monitored target per collection interval, plus the controller's own AP
telemetry and opaque AP/client/mesh configuration snapshots, and renders them
as a per-target latency / loss / SNR / airtime history with an A/B compare
workflow. Collection is **off** on a fresh controller; it is enabled from the
page's gear menu and the setting is stored through ZoneDirector's normal
authenticated preference mechanism.

The three C helpers are compiled **i386, static, musl** by the `analytics-helper`
stage of `docker/Dockerfile`, because the guest is an i386 Linux 2.6.32 system.
They are linked against the SQLite 3.7.17 (2013) amalgamation, a release
contemporary with that kernel; newer SQLite builds return `SQLITE_IOERR` when
opening the guest's live database.

## Vendor dependencies

Like the rest of the appliance userspace, the collectors use what the stock
rootfs already provides:

- `/tmp/getstate.socket` — the vendor `getstatd` local statistics socket
  (queried by `zd1200-local-getstat` for AP/client/mesh views and events);
- `/writable/etc/airespider/ap-list.xml` and `system.xml`;
- `/writable/etc/airespider/ajax_config.log` — the `setpref` journal the page
  writes its monitoring setting to.

Runtime state lives on the writable partition under
`/writable/zd1200-ping-monitor/` and is exposed to the browser through
symlinks in `/web/admin10/`. Nothing is uploaded off the controller.
